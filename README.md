# 🔐 Password Generator Using Python

## 📌 Project Overview
The **Password Generator** is a simple GUI-based application developed using Python and Tkinter. It generates random and secure passwords using uppercase letters, lowercase letters, numbers, and special characters.

The application allows users to enter their desired password length (maximum 10 characters) and generate a random password with a single click.

## 🎯 Objectives
- To generate random passwords automatically.
- To understand Python's built-in modules.
- To implement GUI development using Tkinter.
- To use random character selection.
- To create a simple and user-friendly application.

## ✨ Features
- Simple and user-friendly graphical interface.
- Generates random passwords instantly.
- Supports uppercase and lowercase letters.
- Includes numbers (0–9).
- Includes special characters.
- Maximum password length of 10 characters.
- Displays the generated password on the screen.

## 🚀 How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone https://github.com/your-username/Password-Generator.git
```

**Step 2:** Open the project folder.

```bash
cd Password-Generator
```

**Step 3:** Run the Python file.

```bash
python password_generator.py
```

**Step 4:** Enter the desired password length (maximum 10).

**Step 5:** Click the **Generate** button to create a random password.

## 🖥️ Application Working
1. The application opens a graphical window.
2. The user enters the required password length.
3. When the Generate button is clicked, the program selects random characters.
4. The generated password appears on the screen.
5. If the entered length exceeds 10, an error message is displayed.
